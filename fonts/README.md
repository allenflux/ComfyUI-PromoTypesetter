# 随包字体

本目录随节点一起安装 Noto CJK 简体中文与繁体中文的无衬线（Sans）和衬线（Serif）字体，供真实字体排版使用。字体覆盖中文、英文及常见标点，不需要在 ComfyUI 服务器上手动复制系统字体。

字体来源：[Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk)。字体使用 **SIL Open Font License 1.1**；请保留本目录中的字体许可文件及原始版权信息。节点代码的 MIT 许可不替代字体许可。

语言选项决定简体或繁体的默认字体与字形校验规则；`font_family` 可选择 `auto`、`sans` 或 `serif`。输入字符保持原样，不会因选择字体而进行简繁转换。绘制前会校验所选字体是否覆盖实际输入字符；未覆盖的字符必须通过更换合适字体或由调用方调整输入解决，不能忽略后继续出图。

如替换或增加字体，请同时保留相应许可证，并确认字体许可允许随插件分发。字体文件不是可由空文件替代的占位资源。
